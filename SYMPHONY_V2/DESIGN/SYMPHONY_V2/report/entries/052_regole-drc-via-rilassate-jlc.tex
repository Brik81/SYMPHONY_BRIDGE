\subsection{Cosa \`e cambiato}
Il DRC segnalava errori di anello minimo (\emph{annular width}) su tutte le via: con pad \SI{0,50}{\milli\metre} e foro \SI{0,30}{\milli\metre} l'anello \`e $(0{,}50-0{,}30)/2=\SI{0,10}{\milli\metre}$, mentre la regola custom richiedeva $\ge\SI{0,30}{\milli\metre}$ (ECSS-Q-ST-70-12C Rev.1, 7.5.3f: pad esterno $\ge$ foro $+\,\SI{0,6}{\milli\metre}$).

\subsection{Impatti e criticit\`a}
\begin{critbox}
\textbf{Deviazione ECSS sulle via.} La scheda NON \`e conforme ECSS sulle via (anello \SI{0,10}{\milli\metre} contro \SI{0,30}{\milli\metre} richiesto). La deviazione vale solo per il prototipo: va ripristinata (regola \SI{0,30}{\milli\metre}, \code{.kicad\_pro} a \SI{0,15}{\milli\metre}/\SI{0,55}{\milli\metre}) e gestita con RFD/waiver per una versione di volo.
\end{critbox}
\begin{notebox}
\begin{itemize}
  \item Le net class hanno via \SI{0,45}{\milli\metre}/\SI{0,30}{\milli\metre} (anello \SI{0,075}{\milli\metre}): nuove via piazzate con quei default verrebbero segnalate dal DRC. Da allineare a \SI{0,50}{\milli\metre}/\SI{0,30}{\milli\metre} se Brik81 lo chiede.
  \item Rischi dell'anello sottile: breakout per foratura decentrata e minore affidabilit\`a ai cicli termici.
\end{itemize}
\end{notebox}
